## 1. Project Overview

This repository contains the complete, production-ready React + TypeScript web application for the **Iconic Creation Of God 2026** pageant, makeup seminar, live competition, fashion runway, and grand Bollywood award show. 

The application adapts and preserves the imperial grandeur visual designs, typography, and assets generated by Google Stitch, elevating them into a modular component-driven platform with live database verification, public lookups, and a protected administrative console.

## 3. Implemented Routes

### Public Routes
- **`/` — Home:** Complete Stitch homepage with hero stage, 4 dimensions (Makeup Seminar, Makeup Competition, Fashion Runway, Award Show), crowns of dignity (Mr, Miss, Mrs), Bollywood guest spotlight (Jivitha Sharma), short film casting notice (*‘Devi And Diva’*), ceremony itinerary, organizer profiles, quick registration form, and social media links.
- **`/about` — About Us:** Genesis, vision & mission, detailed profiles of organizers Deven Jha and Ritu Jha, profiles of presenting entities Janta Live News and Deven Jha Productions.
- **`/event` — Event & Activities:** In-depth breakdown of the 4 ceremony sessions, live competition rules, judging criteria, and schedules.
- **`/register` — Registration:** 3-step candidate dossier featuring dynamic circular progress indicator, category selection (Mr/Miss/Mrs), creative tracks, experience levels, portfolio URL, profile photograph upload, duplicate submission prevention (phone/email check), and instant permanent reference generation (e.g. `ICG-2026-REG-XXXX`).
- **`/verify-certificate` — Certificate Verification:** Public ledger lookup supporting real certificate identifiers. Displays recipient photo, conferred title, organizers, SHA-256 seal, scannable QR code, valid, under review, revoked, and void states. Includes print and high-res PDF export.
- **`/verify-award` — Award Verification:** Public portal supporting lookup by either **Award Number** (e.g., `ICG-AWD-2026-992`) OR **Certificate Number** (e.g., `ICG-2026-CERT-0412`). Displays citation, recipient, trophy details, guest of honour, and audit timeline.
- **`/gallery` — Gallery:** High-fashion visual archives with category filtering (All, Runway, Red Carpet, Celebrity, Awards) and full-screen lightbox modal.
- **`/faq` — FAQ:** Interactive accordion addressing candidate eligibility, seminar curriculums, certificates, awards, and venue details.
- **`/contact` — Contact Us:** Functional contact inquiry form with ticket reference logging, venue notice, and social connections.
- **`/privacy-policy` & `/terms` — Legal Pages:** Candidate data protection covenant and pageant participation regulations.

### Admin Console (`/admin`)
*(Hidden from public menus for security)*
- **`/admin/login` — Administrator Sign-in:** Authenticates via Firebase Auth or initial secure setup fallback.
- **`/admin/dashboard` — Dashboard:** Live metrics calculated from stored records (total enrolments, pending review, approved, total certificates, total awards, total inquiries).
- **`/admin/registrations` — Registration Management:** Real-time search, category/status filters, detailed dossier inspection modal, status updates (Pending, Approved, Rejected), record deletion with confirmation, and CSV export.
- **`/admin/certificates` — Certificate Ledger:** Issue new certificates with custom/auto IDs, edit metadata, view scannable QR codes, live certificate specimen render, revoke with grounds, restore, and delete.
- **`/admin/awards` — Award Crypt:** Register awards, link awards to certificates, revoke, restore, inspect citations, and delete.
- **`/admin/enquiries` — Message Management:** Triage inquiries by status (Pending, In Progress, Resolved), read messages, and delete.
- **`/admin/settings` — Website Configuration:** Dynamic editing of event name, date, time, location, organizers, celebrity guest, social URLs, and partner website links.

## 6. How to Run Locally

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation & Execution
```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build & Verification
```bash
# Run TypeScript compilation and build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 7. Firebase & Security Architecture

1. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Populate the Firebase project credentials from your Firebase Console.
3. Deploy Firestore rules using `firestore.rules` provided in the root directory.
4. **Data Isolation:** Public lookups allow certificate and award validation without exposing applicants' private emails, phone numbers, or residential addresses.
